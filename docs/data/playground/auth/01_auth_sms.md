# POST /auth/sms — 发送验证码

## 接口说明

模拟发送短信验证码。Playground 阶段直接在响应中返回验证码，无需真实短信服务。

---

## 请求

| 项目 | 内容 |
|---|---|
| 方法 | `POST` |
| 路径 | `/auth/sms` |
| Content-Type | `application/json` |

### 请求体

```json
{
  "phone": "13800138000"
}
```

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| phone | string | ✅ | 手机号 |

---

## curl 命令

```bash
curl -s -X POST http://localhost:3000/auth/sms \
  -H "Content-Type: application/json" \
  -d '{"phone":"13800138000"}'
```

---

## 响应

### 成功 200

```json
{
  "code": "026895",
  "message": "验证码已发送（playground 模式，直接返回）"
}
```

| 字段 | 类型 | 说明 |
|---|---|---|
| code | string | 6 位随机数字验证码 |
| message | string | 提示信息 |

---

## 测试结果

| 测试项 | 结果 |
|---|---|
| 返回 6 位数字验证码 | ✅ |
| 验证码存入内存供登录使用 | ✅ |
| 重复请求覆盖旧验证码 | ✅ |

### 实际响应记录

```
请求时间：2026-04-24
手机号：13800138000
返回验证码：026895
```

---

## 备注

- 生产环境需替换为真实短信服务（阿里云 / 腾讯云），不再返回 `code` 字段
- 验证码为一次性，登录成功后自动删除
- 重复调用会覆盖上一次的验证码
